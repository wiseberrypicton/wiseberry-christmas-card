WISEBERRY PICTON – INTERACTIVE CHRISTMAS CARD

This folder contains a simple interactive card made from the three original pages of the supplied PDF.

FILES
- index.html: the interactive card webpage
- page-1.png: original envelope artwork (PDF page 1)
- page-2.png: original Christmas card front (PDF page 2)
- page-3.png: original inside message (PDF page 3)

The three PNG artwork files are the supplied PDF pages rendered as images. Their design, wording, colours and layout have not been edited. The webpage adds only the interactions and transitions:
1. Click the envelope to reveal the card front.
2. Click the card front to reveal the inside message.
3. Use Start again to return to the envelope.

PREVIEW
Open index.html in a web browser. Keep all four files together in the same folder.

PUBLISHING
To publish with GitHub Pages, create a new public repository, upload index.html and all three PNG files to the repository's root, then enable Pages in the repository Settings > Pages. Select Deploy from a branch, choose main and /(root), and save. GitHub will provide the public webpage address.
